# School Event RSVP App

A Flutter application that allows students to browse school events, RSVP to attend, view attendee counts, and manage their registered events.

## Features
- Browse upcoming school events
- RSVP and cancel attendance
- View attendee counts
- My Events tab to manage registered events

## Project Scope
- No QR check-in
- No calendar export

## Built With
- Flutter
- Dart

## Getting Started

To run this project locally:

1. Install Flutter SDK.
2. Clone the repository.
3. Navigate to the project folder.
4. Run `flutter pub get`.
5. Run `flutter run`.
